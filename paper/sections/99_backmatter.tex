\section*{Code and Data Availability}
\addcontentsline{toc}{section}{Code and Data Availability}

Code for this study is publicly available at
\href{https://github.com/elendmire/zero-shot-postprocessing}{github.com/elendmire/zero-shot-postprocessing}.
A versioned, archival release of this code is available via Zenodo
(concept DOI: 10.5281/zenodo.22662543, which always resolves to the
latest version; verified by direct Zenodo record inspection, 2026-09-08).
EUPPBench, version \EuppbenchVersion{}, is described in
\citet{demaeyer_2023_euppbench} and distributed via Zenodo (DOI:
10.5281/zenodo.7429236, verified by direct DOI resolution and Zenodo
record inspection, 2026-09-07); this study uses its own defined
train/test split without modification (Section~\ref{sec:data}). TimesFM
3.0 weights (checkpoint \texttt{google/timesfm-3.0-pytorch}) are obtained
from the model card at
\url{https://huggingface.co/google/timesfm-3.0-pytorch} (Section~\ref{sec:covariates}),
distributed under the TimesFM Non-Commercial License v1.0 (verified
against the model card's own license field, 2026-09-07); this study's use
is academic and non-commercial, consistent with that license.
